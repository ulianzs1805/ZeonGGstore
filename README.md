 # ZeonGGStore

Техническое задание и спецификация проекта.

Статус: Beta 1.0

ZeonGGStore — веб-проект с кейсами, Апгрейдером, Контрактами и Башней.

Платформа:
- веб-версия;
- мобильная адаптация;
- серверная обработка данных;
- отдельное хранилище изображений.

Важно:
Все цены и значения, приведённые в документации в качестве примеров, не являются окончательными настройками проекта.

Разработка:
Проект разрабатывается самостоятельно владельцем.

Beta:
На этапе Beta доступ к проекту ограничен.
